# Minimal Three-Node Model: $M_F$

## Status

The current executable three-node model is the **collective-feedback prototype** $M_F$.

It implements:

- local nonlinear node dynamics;
- neighborhood coupling;
- adaptive edge activation;
- metric deformation;
- state-dependent intrinsic distance;
- endogenous collective feedback.

It does **not** implement:

- an explicit admissible set $\mathcal M=\{Z:\Gamma(Z)=0,H(Z)\geq0\}$;
- a tangent or normal space;
- a projection operator;
- projected constraint preservation.

Therefore it must not be described as an implementation of $M_P$ or $M_{FP}$.

## State

The model uses three scalar node states on a complete undirected graph:

$$
x=(x_1,x_2,x_3),
$$

with edge activation variables $s_{ij}$ and metric deformation variables $q_{ij}$.

The executable state is

$$
Z_F=(x,s,q).
$$

The collective statistic is algebraically derived from $x$ rather than stored as an independent state variable.

## Collective mode

$$
c(x)=\frac{1}{3}\sum_{i=1}^{3}x_i^2.
$$

It is generated by the node states and feeds back into node, edge, and metric transitions.

The explicit substrate path is

$$
x\longrightarrow c(x)\longrightarrow(\dot x,\dot s,\dot q).
$$

## Local state dynamics

For node $i$,

$$
\dot x_i
=
\alpha x_i
-
\beta x_i^3
+
\sum_{j\neq i}w_{ij}(x_j-x_i)
-
\chi c(x)x_i.
$$

The conductance is

$$
w_{ij}=a_{ij}\exp(-q_{ij}),
$$

where

$$
a_{ij}=\sigma(s_{ij}).
$$

## Edge activation dynamics

$$
\tau_s\dot s_{ij}
=
\eta_0
-
\eta_1(x_i-x_j)^2
+
\eta_2c(x)
-
s_{ij}.
$$

## Metric deformation dynamics

$$
\tau_q\dot q_{ij}
=
-\gamma q_{ij}
+
\kappa(x_i-x_j)^2
-
\rho c(x).
$$

## Intrinsic edge length

$$
\ell_{ij}
=
\frac{\exp(q_{ij})}{\sigma(s_{ij})}
\sqrt{\epsilon^2+(x_i-x_j)^2}.
$$

The graph metric is the shortest-path distance generated by these edge lengths.

## Exact current claim

The model supports the label:

> **implemented prototype-level downward feedback/constraint**

because a system-derived statistic changes constituent transitions through an explicit substrate path.

It does not establish:

- macro-level causal autonomy;
- organization dependence beyond the encoded equations;
- counterfactual adequacy;
- transport across systems or scales;
- defeat of alternative models;
- empirical emergence;
- equivalence between feedback and projection.

## Relationship to the canonical family

- Removing every $c(x)$ term from constituent transitions defines the intended $M_0$ baseline.
- Adding an explicit admissible manifold and projection without feedback defines target $M_P$.
- Combining separately measurable feedback and projection defines target $M_{FP}$.

Current ceiling:

$$
\boxed{
M_F\ \text{implemented and unit-tested};
\quad
M_P,\ M_{FP},\ \text{and }M_F\equiv M_P\ \text{unverified}.
}
$$

## Interpretation

- Local nonlinear terms provide individual dynamics.
- Neighbor differences provide local coupling.
- The collective statistic provides endogenous feedback.
- Edge activation and metric deformation make connectivity and geometry state dependent.
- The model is a prototype, not a physical law and not yet projected geometry.
