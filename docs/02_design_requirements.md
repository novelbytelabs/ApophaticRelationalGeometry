# Design Requirements

The geometry must satisfy the following requirements.

## R1. Relationality

No node label, coordinate chart, or embedding is physically privileged.

## R2. Locality

Direct state updates depend on the current node and its active neighborhood.

## R3. Global admissibility

The complete configuration restricts which proposed local velocities are jointly possible.

## R4. One-many inseparability

The global condition must be computed from or jointly defined with local and relational variables. It may not be an unexplained external controller.

## R5. Dynamic geometry

States, edge activations, metric deformations, and collective observables may evolve.

## R6. Nonlinearity

The system must permit state-dependent coupling, feedback, saturation, bifurcation, and non-superposable responses.

## R7. Persistence

The current state must carry information from prior evolution.

## R8. Non-collapse

Finite-energy trajectories must not attain zero intrinsic edge length.

## R9. Presentation invariance

Observable predictions must be invariant under admissible relabelings and coordinate transformations.

## R10. Falsifiability

The complete model must make measurable predictions that differ from ordinary local graph dynamics and from static-geometry controls.
