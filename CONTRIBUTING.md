# Contributing

Contributions must preserve the separation between mathematical claims and ontological interpretation.

Every proposed mechanism should include:

1. Exact mathematical definitions.
2. Explicit assumptions and domains.
3. A deterministic reference implementation when computational.
4. Tests for invariance and failure cases.
5. An ablation identifying what the mechanism adds beyond an ordinary dynamic graph.
6. A statement of what evidence would falsify the claim.

Do not add placeholders, hidden fallbacks, untested approximations, or language claiming that the formalism is identical to reality.
